# Sneha Enterprises Website

A static, bilingual Hindi/English website starter for Sneha Enterprises.

## Run locally
Open `index.html` in a browser. No build tools or paid services are required.

## Publish free
You can publish this static site with GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a public repository named `sneha-enterprises-website`.
3. Upload all files in this folder to the repository root.
4. In repository Settings → Pages, choose deploy from branch `main` and folder `/ (root)`.
5. Save and wait for GitHub Pages to provide a free `github.io` address.

A custom domain name usually costs money. Hosting on GitHub Pages can be free for a public repository, subject to GitHub's current plan and usage terms.

## Temporary image
`temporary-brand-image.png` is the uploaded image used temporarily in the homepage hero. It is not a conventional logo; replace it later with the official logo by replacing this file while keeping the same filename, or update the image path in `index.html`.

## Contact and enquiries
The quote form opens WhatsApp with a prefilled message to +91 9004037199. It does not store submissions on a server. The chatbot is an FAQ/rule-based demo, not a connected generative AI service.

## Future upgrades
- Configure a secure server-side form backend if enquiries need to be stored.
- Add email notifications through a provider with a free tier.
- Connect a real AI model only through a secure backend; never put API keys in browser JavaScript.
- Add real portfolio photos and verify all business details before publishing.
